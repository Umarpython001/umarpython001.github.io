About

I started programming in May 2025. Before that I hadn't written a line of code — I picked up CS50P on my own, outside of any class, because I wanted to understand how the things I used every day actually worked. I'm self-taught in the sense that nobody assigned me this; UNILAG's CS program is still mostly ahead of me, since I'm only in my first year.

Python is where I'm most comfortable, and it's still my primary language. I've picked up JavaScript and C alongside it, and I'm currently spending most of my learning time on FastAPI, because I want to get better at building things that other services can actually talk to, not just standalone scripts.

The project I've put the most into is Flask Connect, a full-stack real-time social app. It uses Flask-SocketIO for the real-time layer, SQLAlchemy for the data side, and Flask-Login for auth, and it's deployed on Render. It's the first thing I built that had to hold together as a system — real-time messaging, persistent data, user sessions — rather than as a single script solving one problem.

Where this is going

I want to start a company that builds tech for African markets, specifically in fintech and AI infrastructure. I don't think that's something you arrive at by skipping steps.

Right now that means getting genuinely good at backend development and understanding how systems get built and deployed.

Projects

Flask Connect

A full-stack real-time social app featuring real-time messaging, persistent data, and user sessions. The first system I built that integrated multiple moving parts into a cohesive product.

  • One-on-one and group chat, friend connections, and chat history that survives a refresh.
  • Room IDs are generated deterministically, so a conversation always routes to the same room and two chats never collide.
  • WebSocket transport was failing silently because of a runtime concurrency constraint. I tracked it down and fixed it.
  • There's an AI chatbot in the DMs, built on the OpenAI API, that you can talk to alongside your friends.

Built with

Flask, Flask-SocketIO, eventlet, SQLAlchemy, SQLite, Flask-Login, OpenAI API, deployed on Render

URL Shortener

I built a URL shortener to learn system design properly, and then I tried to break it.

  • FastAPI in front, PostgreSQL for storage, and Redis in between for sub-millisecond reads.
  • I load-tested it with Locust at 100,000+ concurrent users and tuned the connection pools until it held.
  • At one point Windows itself was the bottleneck, so I moved the test environment to Linux.

Built with

Python, FastAPI, SQLAlchemy, PostgreSQL, SQLite, Redis, Locust

LeetCode to GitHub

A Chrome extension that pushes every LeetCode solution I get accepted straight to GitHub, so I never copy and paste them by hand.

  • A content script watches for the "Accepted" result, then grabs the problem title and my code.
  • A Manifest V3 service worker Base64-encodes it and creates or updates a Markdown file through the GitHub REST API.
  • The GitHub token is set from the popup and kept in chrome.storage, so there's no .env file or script to run.

Built with

JavaScript, Chrome Extensions (Manifest V3), GitHub REST API
