## 2. About

I started programming in May 2025. Before that I hadn't written a line of code — I picked up CS50P on my own, outside of any class, because I wanted to understand how the things I used every day actually worked. I'm self-taught in the sense that nobody assigned me this; UNILAG's CS program is still mostly ahead of me, since I'm only in my first year.

Python is where I'm most comfortable, and it's still my primary language. I've picked up JavaScript and C alongside it, and I'm currently spending most of my learning time on FastAPI, because I want to get better at building things that other services can actually talk to, not just standalone scripts.

The project I've put the most into is Flask Connect, a full-stack real-time social app. It uses Flask-SocketIO for the real-time layer, SQLAlchemy for the data side, and Flask-Login for auth, and it's deployed on Render. It's the first thing I built that had to hold together as a system — real-time messaging, persistent data, user sessions — rather than as a single script solving one problem. I also spent time evaluating and setting up cue, an Electron-based AI overlay project, which was more about understanding how an existing AI tool was architected than building something of my own from scratch.

I also co-founded BRIDGE Network, a student tech community, where I run operations and infrastructure. That's meant building out the application system we use to bring people in, choosing the right tools for how the community actually communicates, and handling the unglamorous logistics — emails, forms, process — that make a community function instead of just existing as an idea.

Where this is going: I want to start a company that builds tech for African markets, specifically in fintech and AI infrastructure. I don't think that's something you arrive at by skipping steps. Right now that means getting genuinely good at backend development, understanding how systems get built and deployed, and paying attention to what BRIDGE Network teaches me about running something with other people depending on it. The company is the long-term goal. The projects and the community work are how I'm building toward being someone capable of actually doing it.
